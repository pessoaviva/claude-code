Gerador de Pixel do Meta Mercado Livre

Preencha o ID do seu Pixel, escolha os eventos e copie o código pronto.

Funciona offline — nada é enviado a servidores.

1. Configuração

Encontre em: Gerenciador de Eventos do Meta → Fontes de dados → seu Pixel.
Só para testar no "Testar eventos". Deixe vazio em produção.

2. Eventos

O PageView já vem incluso no código base. Marque os eventos extras e preencha os parâmetros.

3. Código gerado

Cole isto dentro da tag <head> da sua página/landing page.


    

  


  

    ⚠️ Importante para o Mercado Livre: o ML não permite inserir JavaScript dentro
    dos anúncios ou lojas oficiais — então este pixel não roda dentro de um anúncio do ML.
    Use-o em uma landing page / site próprio que direciona o tráfego para seus anúncios
    (o caminho recomendado: anúncio do Facebook/Instagram → sua landing com o pixel → botão que
    leva ao anúncio no ML). Para registrar a compra real concluída no ML, o caminho correto
    é a Conversions API (server-side) usando os dados de pedido — posso gerar essa parte
    depois, se quiser.
